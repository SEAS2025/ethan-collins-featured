# Ethan Collins — Featured Work

Static Cloudflare Pages site for LinkedIn Featured. Highlights six Cursor-built projects.

## Local

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

Then add the `*.pages.dev` URL (or custom domain) to LinkedIn → Featured → Media / Link.
